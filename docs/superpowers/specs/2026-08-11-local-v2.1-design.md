# VoiceInk local v2.1 design

## Goal

Build and install VoiceInk v2.1 from the official `v2.1` tag while preserving the user-owned local-build safeguards and improving unreliable text insertion without removing either paste method.

## Scope

- Keep `LOCAL_BUILD` license behavior and disable Sparkle startup, automatic checks, and manual checks.
- Keep both `Default` (`CGEvent`) and `AppleScript` in the Paste Method menu.
- Persist the user's selected paste method across launches; do not force either method.
- Disable clipboard restoration in `LOCAL_BUILD` so stale clipboard content cannot replace a fresh transcription.
- Disable selected-text capture in `LOCAL_BUILD` because it races with transcription delivery through the same pasteboard.
- Reassert the current transcription immediately before posting the paste command for both methods.
- Preserve the existing VoiceInk preferences, model data, history, shortcuts, and microphone permissions.
- Do not incorporate unpublished upstream `main` changes after `v2.1`.

## Delivery and rollback

The source branch is `codex/free-local-build-v2.1` in `elyutoy/VoiceInk`. GitHub Actions builds an ad-hoc signed artifact with `LOCAL_BUILD`. Before installation, verify the version, build number, signature, policy markers, and executable hash. Quit VoiceInk, move the current app to a timestamped backup on `/Volumes/Work`, install the verified bundle into `/Applications`, and retain the backup until live shortcut tests pass.

## Verification

1. Run policy tests in both `LOCAL_BUILD` and ordinary modes.
2. Prove the new policy test fails before production changes and passes afterward.
3. Build the complete app in GitHub Actions.
4. Verify the downloaded archive and installed executable hashes match.
5. Confirm Settings exposes both paste methods and preserves the chosen method after relaunch.
6. Confirm right Option Push-to-Talk and the mouse-triggered Toggle each insert fresh text without replaying the previous clipboard.

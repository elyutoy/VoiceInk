# VoiceInk Local v2.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and install official VoiceInk v2.1 with the existing free local-build safeguards, reliable clipboard delivery, and both user-selectable paste methods.

**Architecture:** Add one compile-time policy boundary for updater, clipboard restoration, and selected-text capture. Keep official v2.1 paste-method persistence unchanged, strengthen the shared pre-paste clipboard path used by both Default and AppleScript, and build the result in a pinned GitHub Actions workflow.

**Tech Stack:** Swift 6.2, SwiftUI, AppKit pasteboard, CGEvent, NSAppleScript, Sparkle, Xcode 26.2, GitHub Actions.

## Global Constraints

- Base exactly on official tag `v2.1`; do not pull unpublished `main` commits.
- Preserve both `Default` and `AppleScript` in the Paste Method menu and persist the user's choice.
- `LOCAL_BUILD` must disable Sparkle, clipboard restoration, and selected-text capture.
- Preserve application data, models, history, shortcuts, and preferences during installation.
- Keep a recoverable v2.0 backup on `/Volumes/Work` until live verification passes.
